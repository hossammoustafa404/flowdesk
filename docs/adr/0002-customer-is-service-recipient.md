# Customer is the service recipient, not a User Role

**Customer** means the homeowner or site contact an Organization serves. A Customer is not a User and has no login. Jobs link to Customers; phone search drives reuse.

The SaaS-kit practice of calling every non–Super-Admin User a “Customer” is rejected — it collided with field-service language forever. Organization people are Users with an Org Role. Storage codes leftover from the kit (for example a platform flag named `customer`) are legacy labels only until renamed; they must not appear as the product word Customer.
